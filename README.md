# Site Slide Session

Site statique (HTML, CSS, JS, sans build). Ouvrir en local : `node <scroll-craft>/scripts/serve.mjs --root . --port 4500` puis http://localhost:4500.

- Goodies : articles et prix dans `site.js`, tableau `PRODUITS` (prix indicatifs, à confirmer).
- Commandes et demandes de partenariat : ouvrent la messagerie vers `CONTACT` (`site.js`, président). Pas de paiement en ligne.
- Mise en ligne gratuite : glisser le dossier (sans `lab/`, `src/`, `node_modules/`) sur Netlify Drop ou Cloudflare Pages.
